01

Project overview

MISO was created to help university students monitor their finances while becoming more aware of the emotional patterns that may influence their spending.

Many students manage limited monthly allowances while balancing food, transportation, accommodation, academic requirements and social activities.

Although financial tracking applications are widely available, many contain complex features that may not reflect the everyday needs and habits of students.

MISO brings expense tracking, budgeting, savings goals and mood reflection into one mobile application.

02

The problem

Students may know how much money they have spent without understanding the habits and emotions behind their financial decisions.

01

Unrecorded daily expenses

Small purchases can accumulate when transactions are not recorded consistently.

02

Limited spending awareness

Students may only recognise overspending after their available funds have already decreased significantly.

03

Emotional spending patterns

Stress, boredom, excitement and social pressure may influence purchases without the user recognising the connection.

03

Project objectives

  1. Design a mobile financial tracking system for students with income, expense, budget, savings goal and mood-recording components.
  2. Develop an Android application that supports real-time expense input, transaction categorisation, budget monitoring and personal spending insights.
  3. Test the application with student users to evaluate calculation accuracy, feature stability and interface clarity.

04

Core features

MISO organises the most important financial functions around a student's everyday routine.

01

Expense tracking

Record expenses, amounts, categories and transaction dates.

02

Budget monitoring

Compare spending against the user's allocated budget and display budget-limit feedback.

03

Mood check-ins

Record the user's emotional state alongside relevant spending activity.

04

Spending insights

Present spending patterns through summaries, categories and visual charts.

05

Savings goals

Create personal targets and monitor savings progress over time.

06

Reminders

Encourage users to record transactions and review their financial progress.

05

Design and development

Research

Reviewed student financial challenges, existing finance applications and research about financial literacy and spending behaviour.

Planning

Defined the application requirements, information structure, primary user flow and database requirements.

Prototyping

Developed interface concepts and screen layouts in Canva before implementing the Android application.

Development

Built the application with Kotlin and Android Studio, with Supabase supporting the database and user information.

Testing

Tested calculations and application behaviour using the Android Emulator, physical Android devices and student user feedback.

07

Testing approach

Testing focused on application stability, calculation accuracy and whether students could understand the main financial functions.

Functional testing

Verified transaction recording, category selection, calculations, budgets, savings goals and database operations.

Device testing

Checked the application using the Android Emulator and a physical Android phone.

User testing

Collected student feedback through Google Forms to identify usability concerns and areas for improvement.

08

Outcome and reflection

MISO allowed me to combine mobile development, interface design, database integration and user testing within one complete project.

The project strengthened my understanding of Android development, financial data presentation, Supabase integration and designing for a specific user group.

It also showed me that a financial application can do more than display numbers. With meaningful reflection, it can help users recognise the personal patterns connected to their spending.
